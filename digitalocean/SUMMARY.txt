🚀 USAGE EXAMPLES:
─────────────────

1. VERIFY SETUP:
   cd digitalocean/
   ./verify_setup.sh

2. SET CREDENTIALS:
   export DIGITALOCEAN_TOKEN="dop_v1_xxxxx"
   export DO_SSH_KEY_ID="12345678"

3. CREATE STANDARD DROPLET:
   ./create_do_gpu.sh my-test s-2vcpu-4gb

4. CREATE GPU DROPLET:
   ./create_do_gpu.sh my-gpu g-8vcpu-48gb-nvidia-l40sx1-48gb

5. VIEW ALL DROPLETS:
   ./show_droplet_info.sh

6. USE API METHOD:
   ./create_do_api.sh my-api-test s-4vcpu-8gb

7. CHECK LOGS:
   ls -lah logs/
   cat logs/create_doctl_*.log

8. CLEAN UP:
   doctl compute droplet delete --tag-name gpu-demo
